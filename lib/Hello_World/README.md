# Hello World – Introduction to Flutter & Dart

## What Lab Assignment It Covers
- **Lab-1:** Introduction to Flutter & Dart
    - Running the first Flutter app
    - Basic Dart syntax: variables, functions, control structures

## Files Inside
| File | Purpose |
|------|---------|
| `lib/Hello_World/main.dart` | Entry point, Dart basics demo, and Hello World UI |

## Concepts Used
- `StatelessWidget` – for UI that doesn't change
- `MaterialApp` – root app setup with theme
- `Scaffold` – basic page structure (AppBar + body)
- `Center`, `Column`, `Text`, `SizedBox` – layout and display widgets
- Dart basics: variables, functions, if-else, for loop, `debugPrint`

## How to Run in Android Studio
1. Open Android Studio with your phone connected.
2. Go to **Edit Configurations...** (top toolbar dropdown).
3. Click **+** → select **Flutter**.
4. Set **Dart entrypoint** to `lib/Hello_World/main.dart`.
5. Name it `"Hello World"` → click **OK**.
6. Select the config + your device → hit the green **Play** button.

## Expected Output
- App displays **"Hello, World!"** centered on screen.
- Debug console prints Dart variable values, sum, and loop output.
